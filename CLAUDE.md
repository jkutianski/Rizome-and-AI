# Rizome-and-AI — Claude Code Instructions

## Purpose

This repository contains an agent-neutral methodology for analyzing philosophical and conceptual texts through rhizomatic and cartographic thinking.

Claude Code is an execution environment for this methodology. It must not redefine the methodology.

## Before Working

Before substantive analytical work:

1. Read `AGENTS.md`.
2. Identify the applicable Skill in `skills/`.
3. Load relevant protocols from `skills/_shared/`.
4. If executing the complete audit, use `workflows/comprehensive-39-round-audit/SKILL.md`.
5. Use `schemas/` for persistent findings, audit state, and decisions.
6. Consult `agents/claude-code.md` for Claude-specific execution guidance.

## Core Rule

**Analyze before intervening.**

Do not rewrite, restructure, merge, eliminate, or create analytical categories without first establishing that the intervention is warranted.

## Methodological Invariants

Preserve these distinctions:

* AI is not the rhizome.
* Map is not territory.
* The rhizome is dynamic; the map provisionally stabilizes an observation.
* Classification belongs to the map, not necessarily to the territory.
* A node is a concentration of relations and tensions, not a topic or element.
* Connection is not automatically causality.
* Connection is not propagation.
* Propagation is not linear causality.
* An inter-stem node is not merely interdisciplinarity or `AI + X`.
* Complexity is not automatically emergence.
* Multiplicity is not horizontality.
* Technical possibility is not historical inevitability.
* Causal participation is not intention.
* Functional behavior is not automatically understanding.
* Production is not knowledge or evidence.
* Relevance is not authority.
* Authority is not truth.
* AI must not be anthropomorphized without argument.

## Analytical Discipline

Separate:

* observation from interpretation;
* source evidence from inference;
* conceptual problems from stylistic preferences;
* local issues from architectural issues;
* findings from decisions.

Do not invent evidence or manufacture objections.

Analyze the source in its actual language. Do not analyze an imagined translation.

## Persistent State

Treat `schemas/audit-state.md` as persistent investigation memory.

Do not silently discard:

* findings;
* rejected hypotheses;
* unresolved questions;
* preserved decisions;
* previous structural alternatives.

A rejected hypothesis must not be silently resurrected.

## Blind Passes

When a workflow designates a pass as blind, do not import conclusions from previous passes into that analysis.

Follow the isolation requirements defined by the comprehensive workflow.

## Structural Restraint

Before proposing a new node, merger, elimination, or major restructuring, perform the required transversal review.

Do not create categories merely to make the architecture appear more symmetrical or complete.

## Editing

Do not modify source material during analysis unless editing has been explicitly requested or authorized by the applicable workflow.

When editing is authorized, preserve the author's conceptual ownership, voice, asymmetries, and productive tensions.

## Agent Boundary

Claude Code may adapt execution, context management, file operations, and repository interaction.

It must not alter the conceptual framework merely because another analytical formulation appears preferable.

**The repository provides the methodological contract; Claude Code provides the working environment.**
