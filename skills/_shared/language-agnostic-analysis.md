# Language-Agnostic Analysis

## Purpose

This protocol defines how analytical Skills handle source material written in different languages.

The language in which a Skill is written must not determine the language, terminology, or conceptual framework of the source material being analyzed.

## Source Language

* Accept source material written in any language.
* Identify the primary language of the source before beginning the analysis.
* If the source is multilingual, identify relevant language switching and analyze each passage in its original language.
* Analyze the source in its original language whenever possible.
* Do not require translation before analysis.
* Do not translate the entire source into another language as an intermediate analytical step.

## Original Wording

* Preserve original wording whenever a finding depends on a specific expression.
* Preserve quotations, key terms, names, technical terminology, and conceptually significant formulations in their original language.
* When necessary, provide a translation only to clarify the analysis; do not substitute the translation for the original evidence.
* Do not silently normalize terminology across languages.

## Conceptual Analysis

* Evaluate concepts according to their function in the source text, not according to an assumed equivalent in another language.
* Do not treat differences between languages as conceptual inconsistencies by default.
* Do not interpret an unusual translation as evidence of a conceptual problem.
* Distinguish conceptual, methodological, argumentative, semantic, grammatical, translation, and stylistic issues.
* Do not impose terminology from the Skill's language onto the source.
* When apparently equivalent terms have different conceptual ranges across languages, preserve the distinction and identify the relevant semantic difference.
* When a concept has no exact equivalent in the target language, retain the source term when necessary for analytical precision.

## Multilingual Sources

When a source uses multiple languages:

1. Determine whether the language change is incidental, rhetorical, technical, quoted, or conceptually significant.
2. Analyze each formulation in its original linguistic context.
3. Check whether the same concept retains the same meaning across languages.
4. Identify semantic drift only when there is evidence of a meaningful change in scope, ambiguity, reference, or conceptual function.
5. Do not assume that parallel formulations are conceptually identical merely because they appear to be translations of one another.

## Translation

Translation is an analytical aid, not an analytical prerequisite.

When translation is necessary:

* retain the original expression;
* provide the translation separately;
* explain relevant differences only when they affect the analysis;
* avoid treating a translator's choice as equivalent to the author's original formulation.

## Output Language

The language of the Skill does not determine the language of the output.

Unless a specific Skill or workflow establishes another rule:

* follow the user's explicitly requested output language;
* if no output language is specified, use the language of the user's request;
* preserve source-language expressions when they are necessary to support an analytical finding.

## General Principle

Analyze the source that actually exists, in the language in which it exists.

Do not analyze an imagined translation of the source.
